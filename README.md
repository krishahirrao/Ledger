# 📋 Ledger

Ledger is a Full Stack Task Management web application that helps users create, update, organize, and delete daily tasks efficiently. The application is built using HTML, CSS, JavaScript, Node.js, and Express.js.

## 🚀 Features

- Add Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks Complete
- Responsive Interface
- REST API Integration
- JSON-based Data Storage

## 🛠️ Tech Stack

### Frontend

- HTML5
- CSS3
- JavaScript

### Backend

- Node.js
- Express.js

### Database

- JSON

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/krishahirrao/Ledger.git
```

### Install Dependencies

```bash
cd backend
npm install
```

### Start Server

```bash
npm start
```

Server runs locally.
